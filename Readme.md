## Проект 1: Titanic — классификация выживания

**Задача:** предсказать, выживет ли пассажир Титаника.

**Данные:** 891 пассажир, 15 колонок (датасет seaborn).

**Что сделано:**
- EDA: пропуски, распределения, выбросы, корреляции, гипотезы.
- Preprocessing: заполнение `age` медианой по группе, one-hot для `embarked`, логарифм `fare`.
- Модели: LogReg, RandomForest, baseline.
- Метрики: accuracy, precision, recall, F1, confusion matrix, CV.

**Результаты:**
- Baseline: 0.618
- LogReg: **0.826** (победитель)
- RandomForest: 0.815

**Ключевые выводы:**
- `sex` — самый сильный признак (42% важности).
- `sex × pclass` — взаимодействие: женщина 1-го класса 97%, мужчина 3-го 13.5%.
- Recall для «выжил» = 0.65 — модель пропускает 35% выживших.

**Файлы:**
- `01_intro.ipynb` — Iris, первый ML.
- `03_titanic_eda.ipynb` — EDA и модель.
- `titanic_logreg.joblib` — сохранённая модель.
- `predict_titanic.py` — скрипт инференса.

## Проект 2: Погода в Москве — forecasting

**Задача:** прогноз среднемесячной температуры.

**Данные:** RusWeather-GF, 593 станции, 1980–2023.

**Что сделано:**
- EDA временного ряда.
- Лаги, rolling, сезонность.
- Prophet с интервалами.
- Backtesting, hold-out, диагностика bias.

**Результаты:**
- Backtesting (2011–2023): MAE ~2°C, coverage 95.5%.
- Hold-out (2024–2026): MAE 1.82°C, bias +1.24, coverage 83.3%.

**Ключевые выводы:**
- Экстраполяция тренда опасна — модель «увидела» похолодание там, где его нет.
- `changepoint_prior_scale=0.01` даёт осмысленный тренд.
- На 7 лет вперёд — только среднемесячные значения с интервалом.

**Файлы:**
- `06_weather_russia.ipynb` — forecasting.
